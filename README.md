# 🌍 Beecrowd 2057 — Fuso Horário

Solução desenvolvida em **Java** para o exercício **2057 — Fuso Horário**, da plataforma Beecrowd. :chatgpt-content-reference{index="0"}

O objetivo do exercício é calcular o horário de chegada de uma viagem considerando o horário de saída, a duração do voo e a diferença de fuso horário entre a origem e o destino.

---

## 📚 Objetivo

Este exercício trabalha principalmente com:

- Entrada de dados;
- Variáveis do tipo `int`;
- Operações matemáticas;
- Estruturas condicionais;
- `if` e `else if`;
- Ajuste de horário;
- Tratamento da passagem de um dia para o outro.
